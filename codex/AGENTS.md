# Codex Preferences

## Skill Invocation

- Do not use Superpowers skills unless I explicitly mention Superpowers, `@Superpowers`, or a specific `$superpowers` skill.

## GitHub Integration

- Always use the Codex GitHub skill and connected GitHub integration for GitHub repositories,
  pull requests, issues, reviews, comments, checks, and related workflows.
- Do not use the GitHub CLI (`gh`). If the Codex GitHub integration cannot perform a requested
  operation, explain that limitation and ask the user how to proceed instead of falling back to
  `gh`.
